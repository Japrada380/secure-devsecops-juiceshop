# Incident Response

Este directorio contiene los entregables correspondientes al módulo **Detección de Amenazas y Respuesta a Incidentes** de la prueba técnica para Simon Movilidad.

## Contenido

- IOC Enrichment
- Threat Intelligence
- GuardDuty Threat Intel Set
- Reglas Sigma
- Playbook de Contención AWS CLI
- Mapeo MITRE ATT&CK
- Root Cause Analysis (RCA)
- Resumen Ejecutivo para Gerencia
- Plan de Remediación

Los artefactos fueron elaborados a partir del escenario de incidente proporcionado en la prueba técnica y alineados con los requisitos de la rúbrica.
