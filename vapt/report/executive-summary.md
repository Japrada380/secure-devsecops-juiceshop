# Executive Summary

## Assessment

A Vulnerability Assessment and Penetration Test (VAPT) was performed against the OWASP Juice Shop application as part of the Simon Movilidad technical assessment.

The objective was to identify, validate and document security vulnerabilities affecting the application, classify their impact and propose appropriate remediation measures.

## Scope

- Authentication
- REST API
- Product Catalog
- Shopping Basket
- User Management
- File Upload
- Search Functionality

## Methodology

- Manual Testing
- OWASP Testing Guide
- OWASP Top 10
- CVSS v3.1
- CWE Mapping

## Result

The assessment identified multiple security weaknesses across authentication, authorization and input validation mechanisms. Each finding includes evidence, impact, remediation and validation.
